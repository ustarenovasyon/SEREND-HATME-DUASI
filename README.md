# Serhendî Hatme Duası — Android

PDF şartnamesine uygun, tamamen çevrimdışı ezber uygulaması.

## Özellikler
- 12 ders / 30 parça hatme metni
- Dersler serbest açılır, kilit yok
- Ezberledim / henüz ezberlemedim
- Metni gizle/göster, önceki/sonraki parça
- Yerel cihazda ilerleme ve son konum saklama
- Türkçe arayüz, internet izni/isteği yok

## APK
GitHub Actions, her push'ta debug APK oluşturur. Actions sekmesindeki başarılı işten artifact indirilebilir.

## Build
Android Studio ile açın, Gradle Sync yapın ve Build > Build APK(s) seçin.
